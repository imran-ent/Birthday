# 🏆 November 16 — VIP Brotherhood Edition

An interactive, dark-luxury birthday surprise website crafted in velvet obsidian and brushed champagne gold for a best friend's **November 16th** celebration. Designed to balance genuine brotherhood emotion with unapologetic roasts, custom sound effects, and interactive mini-games.

## ✨ Key Features

- **VIP Vault Entrance & Live Chronometer**: Real-time countdown to November 16 that automatically switches into Birthday Mode on the day itself, complete with Web Audio synth fanfare and confetti bursts.
- **Live Personalization**: Update the recipient's name dynamically across the masthead, vault pass, and letter in real time.
- **The 9-Card Evidence & Roast Vault**: Interactive photo gallery with category filters, a full-screen lightbox, and an on-card **🔥 Hype vs. 💀 Roast** toggle for every photo.
- **Smart Photo Sync & Standalone Export**: Drag-and-drop batch photo auto-matching stored locally via `IndexedDB`, plus a one-click **Download File** option that bundles all loaded photos and custom text into a single shareable `.html` file.
- **Bro Club Fun Zone**:
  - **Birthday Perk Roulette**: Spin-the-wheel generator for custom birthday treats and dares.
  - **Brotherhood Vibe Check**: Interactive 3-question mini-quiz.
  - **Midnight Nov 16 Cake**: Blow out the digital candles via click or live microphone blow detection to launch fireworks and unseal the final letter.
- **Sealed Brotherhood Letter**: Luxury stationery letter blending inside jokes and heartfelt appreciation, complete with an inline customization mode.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` (or `birthday_surprise.html`) in any modern browser.
3. Click **Load All 9 Photos** in the top bar (or drag and drop the photos directly onto the page) to sync the gallery, then hit **Download File** if you want a self-contained single-file version ready to send on WhatsApp.

## 🛠️ Built With

- **HTML5 & CSS3** (Custom glassmorphism, 3D card tilt physics, and responsive luxury typography)
- **Vanilla JavaScript** (Canvas confetti & fireworks engine, `IndexedDB` local persistence, and `MediaDevices` microphone blow detection)
- **Web Audio API** (Synthesized celebration chimes and harmonic chords with zero external audio dependencies)
